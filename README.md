# WEB-01 — Site do Lumeterra

Site estático em pt-BR, sem build ou dependências. O repositório `Lumeterra/lumeterra-site` publica a branch `main` automaticamente pela Vercel.

## Download

O endereço configurado em `config.js` é `https://github.com/Lumeterra/lumeterra-releases/releases/latest`. O repositório de releases é público e `/latest` aponta para o release marcado como Latest. Uma pre-release sem a marca Latest não aparece nesse endereço.

## Conteúdo

As imagens da galeria e do hero são ilustrações de conceito e estudos de arte, não capturas de gameplay. O site informa que o visual pode mudar.

A pasta `site/` deste repositório de desenvolvimento é a fonte do conteúdo publicado. Para atualizar, copie seu conteúdo para a raiz deste repositório e envie um commit à branch `main`; a Vercel inicia o deploy automaticamente.
